Sticky notes,
even offline.

Stickly works offline for everyday writing. You do not need an account, and your notes save on your Windows PC. There is no cloud sync, so a note on this computer stays on this computer.

By Dhruvil Mistry · Updated November 11, 2026 · Stickly 0.1.0

What works offline?

You can write plain notes, add checklist items, change paper colors and text sizes, archive and restore notes, pin the window, and peel it to a new position. These features do not need an application server.

Downloading the installer needs internet. Setup may also download Microsoft WebView2 if your PC does not already have it. After setup, everyday note taking works without a connection.

The free preview is for Windows x64. It is unsigned, and it does not have automatic updates. See the installation guide for the current download and setup details.

Where do notes live?

Stickly stores notes, tasks, colors, text sizes, archive history, pin state, and window position in a local JSON file:

%APPDATA%\stickly\data.json

The previous successful save is kept beside it as data.backup.json. The app validates saves and writes them atomically. These files are not encrypted, and a local backup is not protection against losing the entire PC.

This path is for Stickly. Microsoft Sticky Notes uses its own storage and account behavior; these apps do not share files.

Keep your own copy

  1. Quit Stickly using Quit in the system tray.
  2. Open File Explorer and enter %APPDATA%\stickly in the address bar.
  3. Copy the whole folder to a location you control, such as an external drive.

A previous-save backup changes as you keep writing. It is not a permanent archive of deleted notes. For recovery steps, read privacy and storage before replacing either saved file.

What about an account?

Stickly has no sign-in, subscription, or cloud account. The browser sample on this website is separate: it saves sample notes in browser localStorage and does not connect to the Windows app.

Microsoft also supports using its Windows Sticky Notes app locally without signing in. Signing in is used for its cross-device features, as Microsoft explains. Choose based on the app behavior you need, rather than assuming every desktop note needs an account.

Local means local

Stickly currently has no phone sync, shared notes, Microsoft note import, or reminder notifications. Its handwriting, optional checklists, and paper peel are available today; reminders and a daily focus list are planned directions.
