Which Windows version?

Stickly 0.1.0 has been installed and tested on Windows 10 Pro 22H2, 64-bit. The installer targets Windows x64; other Windows versions have not been separately validated. macOS, Linux, and Windows ARM builds are not distributed.

Install Stickly

  1. Download Stickly-Setup.exe from the official GitHub release.
  2. Open the setup file and follow the prompts. It installs for your Windows account, with Start menu and desktop shortcuts.
  3. Open Stickly, then write your first note. Use Alt + N to show or hide the app.

You do not need Node.js, Rust, Git, or a terminal. Setup handles Microsoft WebView2 if it is missing; that first-time runtime download requires internet. Everyday note taking works offline.

About the preview

The current installer is unsigned. Windows may show a publisher or reputation warning. Check that the file came from the official Stickly release before deciding whether to run it.

The release includes SHA256SUMS.txt for verifying the download. Code signing and automatic updates are not available yet.

Verify the download

For an optional integrity check, open PowerShell in your download folder and run:

Get-FileHash .\Stickly-Setup.exe -Algorithm SHA256

Compare the hash with the value beside Stickly-Setup.exe in the release’s SHA256SUMS.txt. A match verifies file integrity; it does not replace a code-signing certificate.

Update or uninstall

To update, choose Quit in Stickly’s system tray menu, then download and run the latest setup again. Existing notes stay in %APPDATA%\stickly. Make a copy of that folder first if you want your own backup.

To uninstall, use Windows Settings → Apps → Stickly. See privacy and storage for details about your saved files.

If setup needs a hand

The note disappeared.
Press Alt + N, or use Show/Hide in the Stickly system tray menu. Closing a note hides the app.
WebView2 could not download.
Check your connection, then run setup again. Microsoft’s WebView2 Runtime page also provides the runtime installer.
Can I use a Mac or Linux computer?
The current download is for Windows x64. Other desktop targets have not been verified or distributed.
I found a bug.
Open an issue on GitHub. Include what you did, what happened, and your Windows version. Avoid including private note contents.
