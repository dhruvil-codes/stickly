Your notes.
On your PC.

Stickly’s desktop app saves your writing locally. There is no Stickly account, application server, analytics client, or cloud sync.

Where notes are stored

The Windows app stores its data in these plain JSON files:

%APPDATA%\stickly\data.json
%APPDATA%\stickly\data.backup.json

They contain note text, tasks, colors, text sizes, archive history, pin state, and the window position. These files are not encrypted. Anyone with access to the files can read them. Window size is not saved yet.

Saves and backups

Stickly validates data and writes saves atomically. It keeps the previous successful snapshot as data.backup.json. If the main file cannot be read, the app leaves it untouched rather than overwriting it.

To make your own backup, quit Stickly and copy the entire %APPDATA%\stickly folder somewhere safe.

To restore the previous save, quit the app first. Back up both existing files. Keep a separate copy of the current data.json, then copy data.backup.json over data.json. Reopen Stickly.

The website sample

The interactive sample runs the real Stickly frontend in your browser. Its notes use this website’s browser localStorage and stay separate from the Windows app. Reset restores the sample notes. Clearing this site’s browser data removes them.

The sample does not provide native window pinning, system tray controls, Windows shortcuts, native resizing, or desktop file storage. Its peel is limited to the sample desk.

This website

The site is hosted on GitHub Pages. It does not add analytics, ad trackers, or third-party font requests. Product videos and font files are served with the site.

GitHub processes requests needed to serve the website and installer downloads under its own privacy statement. Visiting this website is separate from using the offline desktop app.
