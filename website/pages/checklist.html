Sticky notes,
with checkboxes.

In Stickly, start with a plain note, then expand the toolbar and select Add a task. Checklists are optional, so a thought and its next steps can share the same little page.

By Dhruvil Mistry · Updated November 11, 2026 · Stickly 0.1.0

Make a little list

  1. Open a note and write a title or a few lines of context.
  2. Expand the three-dot toolbar and choose Add a task.
  3. Write the task. Press Enter from a task line to add another, or select Add item.
  4. Select a checkbox when you finish. The task dims and gets a handwritten strikethrough.

Click a task’s text to edit it. Select its checkbox again if it needs another go. The small delete control beside a task removes that item.

Make it easy to read

Open Text size in the expanded toolbar and choose S, M, or L. Each note keeps its own size. Writing uses Shantell Sans Bold; Ctrl + B changes the active note text or task to ExtraBold.

Paper color offers classic yellow, pastel peach, blush pink, mint green, sky blue, lavender, and charcoal. Charcoal uses light writing on dark paper.

Resize the window from the lower-right grip. Collapse the toolbar when you want more space for writing. The current preview does not save the window size between sessions.

Keep the next thing close

Select the pin to keep the Stickly window above other windows. Use Alt + N to show or hide it. For more detail, see always-on-top notes.

New note or Ctrl + N creates another page. The small bottom arrows switch pages inside the same window.

Bring a task back

History shows completed tasks and archived notes. Restore a completed task when it becomes relevant again, or restore a whole archived note.

Archiving keeps a note for later. Deleting a note from the trash control is different: it has confirmation, but there is no deletion undo. Closing the window hides the app rather than deleting the note.

Will it remind me later?

Not yet. Checklists record what you want to do, but the current preview has no due dates or reminder notifications. A daily focus list and reminders are planned directions.

Notes and task progress save locally on your Windows PC. See offline notes and backups for the details.
